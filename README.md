## 📘 About the Project

**SmileCare Dental Management System** is a complete clinic management application aimed at improving the workflow of dental clinics.  
It provides a clean interface for receptionists, doctors, admin users, x-ray assistants, and suppliers to manage daily tasks with ease.

---

## 🚀 Features

### 👥 **User Roles**
- **Admin** – Manage all system users
- **Receptionist** – Manage patient registrations and appointments
- **Supplier Manager** – Handle orders & supply items
- **X-Ray Lab Assistant** – Upload & manage X-ray reports
- **Doctor/Dentist** – View patient information & reports

---

### 🛠️ **System Modules**
- ✅ Patient Registration & Profile Management  
- 📅 Appointment Scheduling  
- 💊 Inventory & Supplier Management  
- 🧪 X-Ray & Lab Report Uploading   
- 📂 File Upload Support (X-ray images, documents)  
- 🧑‍💼 Multi-role login system
